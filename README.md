# Xiahan Yu · Portfolio

Static website (HTML / CSS / JavaScript, no build step), designed in Figma.

Pages
- `index.html` — cover with typing intro
- `about.html` — about me, 3D flipping ID badge, CV download
- `portfolio.html` — story folders (click to open; `portfolio.html#video` opens a folder directly)
- `hobbies.html` — hobby folders (hover to open, click for the album)
- `album.html?a=traveling` — photo albums with 3D page turns

Run locally: `python3 -m http.server 8000`, then open http://localhost:8000
